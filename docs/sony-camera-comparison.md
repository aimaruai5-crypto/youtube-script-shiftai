# 会社用カメラ比較：α6700 / α7C II / α7 V

作成日：2026-08-03
対象：ソニー αシリーズ 3機種（法人での購入検討用）

---

## 0. 結論（先に）

| 状況 | おすすめ |
|---|---|
| 会社の「万能1台目」を予算バランス良く | **α7C II** |
| 動画がメイン。長回し・複数カメラ・納品品質重視 | **α7 V** |
| 予算を抑えつつ機動力重視。レンズ込みの総額を安く | **α6700** |

**迷ったらα7C II。** フルサイズの画質・暗所耐性・ボケが手に入り、サイズと価格の妥協が一番少ない。
ただし「動画を本気でやる」「1年に何十本も撮る」なら、価格差を飲んででも**α7 V**が正解になる。

## 2. 機種別 メリット・デメリット

### α6700（APS-C／約18万円）

**メリット**
- **圧倒的に安い**。同じ予算でレンズを2〜3本揃えられる
- 約493gと最軽量。ジンバル搭載・一日中の手持ち撮影・出張が楽
- APS-Cレンズが安く小さい。**システム全体の総額が最も安い**
- 望遠が1.5倍相当で有利（イベント・スポーツ・登壇者の寄り）
- 被写界深度が深く、**商品撮影・物撮りでピント面を確保しやすい**
- AI被写体認識はフルサイズ機と同世代。AF性能は価格に対して破格

**デメリット**
- 暗所性能でフルサイズに1段強劣る。**薄暗い会議室・夜の現場では画質差が出る**
- 大きなボケを作りにくい（インタビューの背景ボカしは物足りない場合あり）
- ファインダーが236万ドットと小さめ、SDシングルスロット
- 4K60pのクロップが大きく、広角が苦しい
- メカシャッター最高1/4000秒。明るい屋外でF1.4開放を使うとNDフィルタ必須
- ローリングシャッター歪みが出やすい（速いパン・動く被写体）
- 「フルサイズじゃない」ことがクライアントワークで説明を要する場面がある

**向いている用途**
社内イベント・展示会の記録、SNS用の短尺動画、Vlog、屋外ロケ、商品撮影、
出張が多く機材を軽くしたいケース、**「1人で全部撮る」担当者の相棒**。

---

### α7C II（フルサイズ／約22〜23万円）

**メリット**
- **フルサイズ3300万画素を約514gで持ち運べる**。この軽さは他社にほぼ無い
- 4K30pまではフルサイズ7Kオーバーサンプリング。**解像感が非常に良い**
- 高感度に強く、暗所・室内・夕方の撮影が安定
- 背景を大きくボカせる。**インタビュー・人物・社長挨拶の「それっぽさ」が段違い**
- 手ブレ補正7.0段。手持ち動画・歩き撮りが安定
- 価格差はα6700から約5万円。**フルサイズ入門としてコスパが良い**
- フルサイズレンズ資産がそのまま将来のα7 Vなどに引き継げる

**デメリット**
- **ファインダーが236万ドット・0.70倍と小さく暗い**。写真をしっかり撮る人には最大の不満点
- SDシングルスロット。**バックアップが取れない＝仕事の撮影ではリスク**
- 4K60pはSuper35クロップ。広角が足りなくなる
- 4K120pのスローは撮れない
- グリップが浅く、**大三元など重いレンズを付けると持ちにくい**
- ボタン・ダイヤルが少なく、設定変更はメニュー依存になりがち
- 連写10コマ/秒、ローリングシャッター歪みは残る

**向いている用途**
広報用の写真＋動画を1台で回す、採用サイト・コーポレートサイト用の人物撮影、
インタビュー動画、YouTube用の据え置き撮影、**「軽くてちゃんと綺麗」を両立したい会社の基準機**。

---

### α7 V（フルサイズ／約41.7万円）

**メリット**
- **部分積層型センサー**で読み出し約4.5倍高速 → **ローリングシャッター歪みが激減**
- 電子シャッターで**30コマ/秒**。動きもの・イベントの決定的瞬間に強い
- **4K60pがフルサイズ・ノークロップ**（7Kオーバーサンプリング）。画角を犠牲にしない
- **4K120pのスローモーション**が撮れる（Super35）
- **4K60pの連続記録が約60分**（α7 IVは約10分）。USB給電でさらに長時間。
  → **セミナー・対談・ウェビナーの長回しに耐える**
- **デュアルスロット（CFexpress Type A/SD ＋ SD）**。同時記録でデータ消失リスクを潰せる
- ファインダー約369万ドットで見やすい。多軸モニターで自撮り・ローアングル両対応
- AI認識精度が約30%向上、AFカバー率94%。手ブレ補正7.5段
- **業務用として一番「事故らない」**

**デメリット**
- **価格が約41.7万円**。他2機種の約2倍で、決裁のハードルが高い
- 約695gとやや重い。レンズ込みで1.5kg級になり、長時間手持ちはきつい
- CFexpress Type Aカードが高価（メディア代を予算に見込む必要あり）
- 機能が多く、使いこなすには設定の理解が要る。**カメラ初心者だけの体制ではオーバースペック**
- 写真の画質そのものはα7C IIと同じ3300万画素。**静止画メインなら価格差ほどの差は出ない**

**向いている用途**
YouTubeチャンネル運用、ウェビナー・セミナー収録、対談・複数カメラ撮影、
納品を伴う制作案件、展示会やスポーツなど動きものの撮影、
**「会社の映像制作を内製化する」フェーズのメイン機**。

## 3. 用途別の選び方

| 用途 | 最適 | 理由 |
|---|---|---|
| YouTube・動画を継続運用する | **α7 V** | 4K60pノークロップ、長回し耐性、デュアルスロット |
| セミナー／ウェビナーの長時間収録 | **α7 V** | 連続記録約60分＋USB給電、記録冗長化 |
| インタビュー・社長挨拶・採用動画 | **α7C II** | ボケと暗所耐性。この用途なら価格差ほどの機能差は出ない |
| 広報の写真撮影（Web・パンフ） | **α7C II** | 3300万画素で十分。α7 Vと静止画画質は同等 |
| 商品・物撮り | **α6700** | 被写界深度が深く扱いやすい。三脚固定なら手ブレ補正差も無関係 |
| 社内イベント・展示会の記録 | **α6700** | 軽量＋望遠1.5倍。動き回る撮影で疲れない |
| SNS短尺・Vlog | **α6700** | 軽い、安い、AIオートフレーミングが便利 |
| スポーツ・動きもの | **α7 V** | 30コマ/秒＋歪みの少ない電子シャッター |
| 複数人で使い回す社内共用機 | **α7C II** | 価格・重量・操作の総合バランス。壊れても被害が小さい |

## 4. 予算で考える現実解

**レンズ込みの総額で比較すると印象が変わります。**

| 構成 | ボディ | 標準ズーム目安 | 合計目安 |
|---|---|---|---|
| α6700 + APS-Cズーム | 約18万 | 約8〜12万 | **約26〜30万** |
| α7C II + フルサイズズーム | 約23万 | 約12〜20万 | **約35〜43万** |
| α7 V + フルサイズズーム + CFexpress | 約42万 | 約12〜20万 | **約56〜65万** |

- 予算30万円以内 → **α6700**
- 予算40万円前後 → **α7C II**（会社の1台目として最も無難）
- 予算60万円以上／動画を本業に近い形で回す → **α7 V**

**将来の拡張性という観点では、α7C IIを買っておくとレンズがそのままα7 Vに引き継げます。**
逆にα6700でAPS-C専用レンズを揃えると、後でフルサイズに移行する際にレンズを買い直すことになります。
「いずれフルサイズに行く」と分かっているなら、最初からα7C IIを選ぶほうが結果的に安くつきます。

## 5. 判断を分けるポイント（1行で）

- **1スロットで仕事の撮影ができるか？** → 撮り直しの効かない現場があるならα7 V一択
- **フルサイズのボケが必要か？** → 人物を撮るなら必要。物撮りなら不要
- **長回しするか？** → 30分を超える収録が定期的にあるならα7 V
- **誰が使うか？** → カメラ初心者中心ならα6700かα7C II。設定の複雑さは戦力を落とす
